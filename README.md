## 📖 Sobre o projeto

O **ParkSESI** é um sistema web desenvolvido para modernizar o controle de estacionamento do SESI, substituindo os registros manuais por um gerenciamento digital.

A plataforma centraliza as informações de colaboradores, veículos e visitantes, proporcionando mais organização, agilidade e eficiência no controle de acesso.

## 🎯 Objetivo

Desenvolver uma solução digital capaz de facilitar a administração do estacionamento, permitindo acompanhar a movimentação de veículos, controlar vagas e manter os registros organizados.

## 👥 Público-alvo

O sistema é destinado aos seguintes públicos:

| Público | Descrição |
|---|---|
| 🛡️ Porteiros | Responsáveis pelo registro de entradas e saídas e pelo controle de acesso. |
| ⚙️ Administradores | Responsáveis pelo gerenciamento do sistema e acompanhamento das movimentações. |
| 👤 Colaboradores | Usuários vinculados à instituição que utilizam o estacionamento. |

## ⚙️ Como funciona?

O ParkSESI funciona por meio de uma aplicação web com autenticação e controle de acesso conforme o perfil do usuário.

Seu funcionamento acontece por meio das seguintes etapas:

1. **Login:** o usuário realiza a autenticação para acessar a plataforma.
2. **Cadastro:** são registrados colaboradores e seus respectivos veículos.
3. **Entrada e saída:** a portaria registra a movimentação dos veículos.
4. **Controle de vagas:** permite acompanhar a ocupação do estacionamento.
5. **Visitantes:** possibilita registrar e acompanhar os acessos de visitantes.
6. **Histórico:** disponibiliza os registros das movimentações realizadas.
7. **Administração:** permite gerenciar usuários e acompanhar as informações do sistema.
